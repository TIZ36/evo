DSH 不给客户端插件开放导航 API

2026-08-20 09:41 从 session 8f3a 第 4 轮蒸馏 · 此后被召回 5 次 · 最近一次 2 小时前
作用域 cwd · evo · 置信度 0.86

DSH web 客户端插件（window.__ModuleLoader__.load + ctx.slots）没有 router / navigate / openSettings 服务。openSection(id) 只作为 owner props 下发给 settings.onboarding 的注册者，且只在空会话 onboarding 阶段挂载；settings.section 注册者只拿得到 close。 根因是 Settings 的 open/activeId 存在 SettingsRoot 组件的局部 React state 里，没暴露成 cordis service。 需要程序化打开 Settings 某 section 时走 DOM：先点 button[aria-haspopup="dialog"]，再在 [role="dialog"][aria-modal="true"] 里按可见文本匹配导航项并 click（点最内层元素，事件会冒泡到 nav row 的 handler）。不要依赖哈希类名——宿主改版即碎。
